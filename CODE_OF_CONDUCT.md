# Code of Conduct

Treat contributors and users with respect. Discuss code and ideas without personal attacks.
Harassment, threats, discrimination, sexualized behavior and sharing another person's private information are not acceptable.

Use synthetic examples and keep customer data out of public discussions. Respect people's time and different levels of experience.

Maintainers may remove inappropriate content, close disruptive threads or restrict participation when necessary.
Report abusive content through GitHub's **Report content** control. Use the private security reporting channel only for software vulnerabilities.

These expectations apply to this repository's issues, pull requests and other project spaces.
