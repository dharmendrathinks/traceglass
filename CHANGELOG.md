# Changelog

## 0.1.0 — 2026-10-04

First public release.

- Explicit network recording inside Chrome DevTools and a standalone local workspace.
- HAR and portable capture imports parsed in a bounded worker.
- Before/after comparisons for failure rates, median latency, repeated requests and transfer size.
- Route inspection, shared-scale waterfalls, configurable thresholds and request/transfer/error budgets.
- Local IndexedDB capture library with editing, export and deletion.
- Offline HTML and Markdown reports.
- A light interface, responsive navigation and a three-step introduction.
- Synthetic example captures and a reproducible local checkout fixture.
- MIT licensing, contribution and security guidance, and GitHub Actions verification.

No Chrome Web Store publication, automatic test replay, cloud accounts or billing is included.
