Traceglass's first public release: record the same website actions before and after an update, then compare the network requests locally.

## Install in Chrome

1. Download **traceglass-0.1.0.zip** from the assets below and extract it into a permanent folder.
2. Open `chrome://extensions`, enable **Developer mode**, and choose **Load unpacked**.
3. Select the extracted folder containing `manifest.json`.
4. Open a website, then **DevTools → Traceglass → Explore the example**. Reopen DevTools if the panel is not visible.

The ZIP is the installable extension. GitHub's automatic **Source code** archives require a development build. This release has not been published to the Chrome Web Store.

## Included

- Explicit DevTools recording and local HAR/JSON imports.
- Before/after comparisons for failed responses, slower routes, repeated calls and added transfer weight.
- Route inspector, waterfalls, policies, budgets and a local capture library.
- Offline HTML and Markdown reports.
- A light interface with a three-step introduction and responsive navigation.
- Synthetic examples, a local test fixture, MIT license, contribution docs and CI.

## Data and limits

No accounts, telemetry, remote code or cloud upload. Captures exclude headers, cookies, bodies and query values; hostnames, normalized paths and user notes may still be sensitive. Recordings do not automatically replay actions. GraphQL/query-based operations may be grouped together, and two recordings do not establish statistical significance. See the README and privacy notice for full boundaries.

Validation includes 48 unit tests and 8 browser tests covering real DevTools recording, imports, reports, persistence, accessibility and compact layouts. Chrome 120+ is declared; browser tests use Playwright's pinned Chromium rather than certifying every supported Chrome release.

The accompanying `.sha256` file verifies the extension ZIP. The archive includes `LICENSE.txt`, `PRIVACY.txt` and `THIRD_PARTY_NOTICES.txt`.
